# SPW Tag Workbench

适用于 Salt Player for Windows（SPW）的音乐标签工作台插件。支持在线批量匹配封面和逐字歌词、查看歌曲频谱图，并在写入文件前集中编辑、预览音乐标签信息。

> 本项目是非官方社区插件。在线数据来自相应音乐服务，接口可用性可能随服务调整而变化。

## 主要功能

### 音乐库与歌曲列表

- 保存并管理多个音乐文件夹，打开工作台时自动合并扫描。
- 支持手动添加音频、清空临时列表和重新扫描已保存目录。
- 支持 MP3、FLAC、M4A、OGG、Opus、WAV、WMA。
- 文件扫描和标签读取按 CPU 逻辑线程动态并发，最高 32 个工作线程；界面更新统一回到 Swing 事件线程。
- 普通列表显示标题、艺术家和专辑；展开后增加时长、位深、比特率，并可调整列宽和列顺序。
- 表头复选框可全选或取消全选；搜索会实时匹配除歌词外的全部标签内容。
- 匹配结束后自动把失败或不完整歌曲移到列表前方，并保留勾选；完整成功项取消勾选。
- 鼠标悬停可查看被列宽截断的完整内容，滚动后提示会自动关闭。
- 勾选“跟随播放”后，SPW 当前播放或切换到的本地文件会加入列表并定位。

### 标签预览、编辑与写入

可读取、预览、编辑并写入：

- 标题、艺术家、专辑、专辑艺术家
- 年份、音轨号、碟号、风格
- 作曲家、作词家、注释
- 歌词与封面

匹配结果首先进入工作台预览，不会自动修改音乐文件。确认内容后使用“保存当前”或“保存选中”才会写入。空值、`0`、`unknown` 等无效返回不会覆盖原标签；缺少可靠依据时也不会把接口默认音轨号 `1` 写入空标签。

### 在线来源

| 来源 | 基本标签 | 封面 | 逐字歌词 | 普通歌词 |
| --- | --- | --- | --- | --- |
| QQ 音乐 | ✓ | ✓ | QRC | ✓ |
| 酷狗音乐 | ✓ | ✓ | KRC | ✓ |
| 网易云音乐 | ✓ | ✓ | YRC | ✓ |
| Apple Music | ✓ | ✓ | — | — |
| 聚合源 | 多来源补齐 | 多来源补齐 | 逐字优先 | 自动兜底 |

来源菜单顺序为 QQ 音乐、酷狗音乐、网易云音乐、Apple Music。Apple Music 当前仅用于标签和封面，不参与歌词候选列表。

列表区域的右键菜单作用于所有勾选歌曲，可分别匹配全部、封面或歌词；封面和歌词区域的右键菜单只作用于当前显示歌曲。上方来源按钮决定工具栏“匹配选中”所使用的来源。

## 匹配逻辑

匹配不是直接采用平台搜索第一条，流程如下：

1. 使用本地标题检索；标题为空时使用不含扩展名的文件名。
2. 先查询完整标题，再查询首个圆括号、方括号或影视说明分隔符之前的可读核心标题。
3. 标题查询无法取得可接受结果时，才使用“标题 + 本地艺术家”补充检索，避免过早缩小搜索范围。
4. 单个平台可检查最多 24 条备选结果。先确认标题是完全一致、核心标题一致或具有足够相似度，再校验艺术家。
5. 本地和平台均有时长时，允许约 6% 的误差，并限制在 12–20 秒内；时长未知不会单独否决标题和艺术家已通过的结果。
6. 多个结果通过后，优先选择时长最接近者，再比较标题、艺术家、专辑相关度，最后比较歌词、封面和标签完整度。
7. 需要歌词时，同等结果优先选择确实返回歌词的歌曲；逐字歌词优先于普通逐行歌词。
8. 聚合源依次尝试 QQ 音乐、酷狗音乐、网易云音乐和 Apple Music，并把不同来源的可用字段合并。标题、艺术家、专辑、封面和逐字歌词齐全后提前结束。
9. 主搜索结果缺少封面时，会继续检查该来源的其他封面结果；聚合源会按来源继续补充，并再次执行标题、艺术家和时长校验。
10. 匹配只更新所选范围：标签、封面或歌词。没有返回的字段保留本地原值，失败结果不会覆盖预览。

标题比较会忽略大小写、空白和标点，并把括号中的 `ver`、`version`、`版`、`edit` 等文字视为附加说明。括号或影视剧说明前的核心标题相同会提高相关度，而不会仅因 Live、Movie edit、主题曲等平台标注差异直接拒绝同一音频。

## 歌词预览与格式转换

双击歌词区域可进入高级预览：

- QQ 音乐、酷狗音乐、网易云音乐并行返回多条结果。
- 默认优先按本地音频时长接近程度排序，再比较标题相关度，最后按 QQ、酷狗、网易云的来源顺序排列。
- 双击某条结果后，将歌词载入右侧编辑器；载入和格式调整仍只影响预览。
- 可输出 `LRC（逐字）`、`LRC（逐行）`、`LRC（ESLyric）`、`SRT`、`ASS` 和纯文本。
- 可实时开关原文、译文、罗马音，调整时间偏移，并进行简体/繁体转换。
- 原文保留词级时间戳；译文使用行级时间戳。会过滤空译文、`//` 占位、与原文重复的译文及重复制作信息。
- 没有逐字歌词时自动使用普通歌词；完全没有歌词才记为失败。

## 封面预览

双击封面可进入多源预览：

- 并行查询 QQ 音乐、酷狗音乐、网易云音乐和 Apple Music。
- 已返回图片排在加载中或无结果项之前。
- 保持图片原始比例，展示实际像素和文件大小，不统一强制缩放为固定尺寸。
- 可选择在线结果应用到当前预览，也可导入本地 JPG、PNG、WebP、GIF。
- 支持按原图片类型导出当前封面。

同一轮处理中，相同图片地址会共享下载任务，避免并发重复下载；退出封面预览后清除候选和临时缓存，下次进入重新加载。

## 歌曲频谱图

- 复用 SPW 已加载的 BASS 音频引擎进行解码，不额外打包 FFmpeg、BASS 或 JNA。
- 立体声音频分别绘制左、右声道；单声道自动使用完整区域。
- 两侧显示频率刻度，主图按时间横向推进、频率纵向排列，底部为连续时间轴能量柱状总览。
- 频谱计算与图像生成在后台线程执行，页面关闭后取消任务并释放解码流和图像缓存。

## 批量操作与临时日志

- 批量匹配显示处理数量、百分比、成功和失败数量。
- 日志按歌曲、来源和处理范围记录成功、近似匹配、普通歌词降级、缺少封面/歌词、网络异常及写入异常。
- 汇总行记录请求数、实际匹配数、完整数、预览数、失败数、跳过数、线程数和耗时。
- 普通信息使用默认色，警告使用黄色，失败或异常使用红色。
- 日志仅存在于当前工作台内存中，不创建日志文件；关闭工作台即清空。

## 配置

- **跳过已有完整标签的歌曲**：标题、艺术家、专辑、封面和歌词均存在时，不请求在线来源，也不写入匹配结果。
- **SPW 音乐文件夹**：添加、删除和保存多个自动扫描目录。
- **打开标签工作台**：进入批量匹配、预览、编辑和频谱界面。
- **开源项目**：打开本仓库。

## 界面与资源管理

- 适配 SPW 深浅色，使用 MiSans（不可用时回退 Microsoft YaHei UI）、圆角组件、圆角菜单和沉浸式滚动条。
- 页面动画按工作台所在显示器的当前刷新率调度。
- 常用页面框架在工作台启动后预布局；封面结果、歌词候选和频谱图等瞬态数据在退出对应页面时释放。
- 关闭工作台会取消扫描、匹配、下载和频谱任务，停止动画及滚动计时器，清理监听器、图片、缓存、日志与窗口引用。
- 插件只释放自己创建的 BASS 解码流，不初始化或关闭 SPW 的全局音频引擎。

## 安装

1. 从 [Releases](https://github.com/univers629/SPW-Tag-Workbench/releases) 下载 `SPW-Tag-Workbench-1.0.0.zip`。
2. 在 SPW 创意工坊的本地插件管理中导入 ZIP。
3. 在模组配置页添加音乐文件夹，然后打开标签工作台。

要求：SPW 1.15.2 或更高兼容版本、Java 21 运行环境。

## 构建

```powershell
.\gradlew.bat clean build plugin
```

构建产物位于 `build/distributions`。构建目录、Gradle/Kotlin 缓存、IDE 文件、日志、崩溃转储、环境变量文件和误建的嵌套仓库均已通过 `.gitignore` 排除。

## 使用提醒

- 建议先少量歌曲测试，确认匹配结果后再批量保存。
- 在线来源可能因地区、网络或服务接口调整暂时不可用。
- 请只整理你有权修改的本地音乐文件，并遵守当地法律及各服务条款。
